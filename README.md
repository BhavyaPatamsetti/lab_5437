# Web Application Development Lab

An archive of exercises in HTML structure, CSS selectors, forms, browser events, JavaScript, and basic Node.js.

## What is included

- HTML examples include lists, tables, links, images, forms, resumes, and calculators. JavaScript examples include functions, mouse events, and asynchronous behavior.

## Getting started

Open individual `.html` files in a browser. Read the accompanying JavaScript before running Node-specific examples. `index.html` is one exercise, not a complete index of the collection.
